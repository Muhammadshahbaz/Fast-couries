# Run Courier Rate Card Baseline

These seeded rates are stored in `courier_rates.rate_slabs` and used by the seller booking page.

## Leopard / Trax / M&P / BlueEx

- 0-0.5 KG: Rs.248.99
- 0-1 KG: Rs.281.88
- Extra KG: Rs.156.60

## TCS

- 0-0.5 KG: Rs.280
- 0.6-1 KG: Rs.300
- Extra KG: Rs.300

## Overland

- 0-5 KG: Rs.450
- Extra KG: Rs.100

## Settlement Deductions

- Bank charges: Rs.85 per invoice
- Cash handling: 1%
- COD: 4%

Bank charges and handling deductions are invoice-level settlement charges. They are not added to each parcel's shipping charge because one invoice can include many parcels.
